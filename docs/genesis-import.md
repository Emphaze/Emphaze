# Импорт базы «Генезис»

Конвертер готовит файл для штатного импорта сайта «Космический корабль Генезис». Он читает локальный JSON с данными шести листов Google Sheets, не обращается к AppSheet, не подключается к Cloudflare и не меняет опубликованную базу.

```sh
node scripts/import_genesis.mjs workbook.json genesis-ready.json
```

Результат — `genesis-ready.json` с состоянием сайта и соседний `genesis-ready.report.json` с результатами сверки и отсутствующими данными. В состоянии нет обёртки `{state, report}`: его можно выбрать непосредственно в разделе импорта сайта. Перед заменой текущего состояния сохраните его резервную копию штатной кнопкой экспорта.

Скрипт также экспортирует функцию без побочных эффектов:

```js
import { convertGenesisWorkbook } from './scripts/import_genesis.mjs';

const { state, report } = convertGenesisWorkbook(workbook, {
  now: '2026-10-15T10:00:00.000Z',
});
```

`now` задаёт дату отчёта. Функция не меняет входной объект и при одинаковом содержимом и `now` возвращает одинаковые данные, включая идентификаторы.

## Формат исходника

Источник — таблица [«Генезис»](https://docs.google.com/spreadsheets/d/1nWc9ZuLXj-ak4ukKscmOM-_BzeJfBKQngirGgpalTEI/edit). XLSX предварительно преобразован в массив листов с адресами ячеек и сохранёнными значениями:

```json
[
  {
    "name": "Альянсы",
    "rows": [
      {"row": "1", "cells": {"A1": {"value": "Альянс"}}},
      {"row": "3", "cells": {"A3": {"value": "Название"}}}
    ]
  }
]
```

Это сокращённая иллюстрация структуры; для импорта нужны все обязательные листы и столбцы. Числа вида `"1200.0"` допустимы, дробные значения показателей — нет. Формулы не вычисляются: используется только сохранённое `value` ячейки.

| Лист | Столбцы |
| --- | --- |
| Альянсы | A — имя, D — крышечки, F — опыт, H — уровень и исходная заметка |
| Подфункции | A — имя; D/F/H/J — репутация инженеров/астрофизиков/астробиологов/архивариусов; L — ОД райдеров; N/P/R — Кадия/Фенрис/Кронус |
| Интерфейс | A — имя альянса, D — гравитоны, F — заряд или заряд/ёмкость |
| Прокачка | A — название, B — цена, C — эффект, D — крафт |
| Эквип | A — название, B — эффект или уровень инструмента, C — крафт |
| Доступ | A — эффект, C — цена, E — название |

Заголовки располагаются в строке 1. Пустые строки пропускаются. Альянсы сопоставляются по именам после нормализации Unicode NFC и пробелов; похожие, но разные буквы не подменяются. Не хватает строки связанного листа, есть лишний альянс, повтор имени, неверное число или неполный каталог — импорт завершается ошибкой до записи результата.

## Что переносится

Каждый альянс создаётся без демонстрационных искателей и владений. Идентификаторы `genesis-alliance-1`, `genesis-alliance-2` и далее соответствуют порядку строк листа «Альянсы».

Шкала опыта: 0, 100, 200, …, 9900. Первый уровень начинается с 0 опыта. Разница между исходным уровнем и `floor(опыт / 100) + 1` становится отдельным `bonusLevels`: находка на карте продолжает давать уровень после новых наград. Отрицательная разница считается ошибкой. У Гагарина из явной записи `6+расщепитель 1` устанавливается только «Лазерный расщепитель I».

Гравитоны переносятся полностью, общего предела 10 нет. Эквип сохраняет игровое ограничение в десять покупок за путешествие. Служебный `gravitonsPurchased=0` начинает учёт после переноса; исходная история покупок неизвестна. Этот счётчик скрыт в интерфейсе.

Из записей `200/300` и `300\300` показывается текущий заряд. Старые значения ёмкости, стойкости и количества покупок остаются в данных для совместимости резервных копий и технического отчёта; в интерфейсе и заметках о пропущенных данных они скрыты. Заряд можно изменять без верхнего предела, при нулевом заряде сохраняется 0. Простой вызов `updateInterface(state, id, {name, charge, gravitons})` сохраняет прежние скрытые значения, а технический `maxCharge` автоматически расширяется при необходимости.

Числовые аванпосты и узлы становятся записями с пометкой «название не указано». Бонусы аванпостов остаются неизвестными (`bonusKnown=false`), награды не выдаются. Запись Кадии `3 действия бесплатно` остаётся заметкой. Запись Фенриса `6 3дейтсвия бесплатно` создаёт шесть узлов и сохраняет весь текст. Поимённый шаттл создаётся только при наличии слова «Шаттл» и имени после него; бонус без имени не создаёт шаттл. Исходные записи сохраняются в `sourceNotes` без исправления текста; `-` не переносится как заметка.

Сверяются все 27 улучшений, 42 предмета эквипа, 30 инструментов и 11 устройств из листа «Доступ». Отсутствие любой позиции останавливает импорт. Цены, эффекты, уровни инструментов и текст рецептов из источника имеют приоритет через `itemOverrides`, а стабильные идентификаторы и механика крафта сохраняются. `normalizeGenesisItem` исправляет только целиком распознанные прежние формулировки шести эффектов: бонус Десантного форсажа, описание Гравитона и термин «модульный интерфейс». Эти изменения перечисляются в `report.catalog.normalizedEffects`; авторские эффекты и цены сохраняются. Два варианта девяти улучшений подтверждены механикой. Остальные неоднозначные рецепты требуют прежней проверки; несуществующий «Форпост» в рецептах «Пионера» и «Магеллана» не заменяется догадкой.

## Что остаётся неизвестным

В выгрузке 15 октября 2026 года неизвестны максимальная ёмкость четырёх интерфейсов, стойкость всех восьми альянсов и прошлые поступления крышечек. Стойкость и накопленные поступления хранятся внутренним нулём с флагами `resilienceKnown=false` и `earnedCapsKnown=false`. Новые награды считаются после импорта. Не заданы полный инвентарь, искатели, полученные устройства, большинство установленных улучшений, отдельные ОД Кадии и история покупок гравитонов. Скрытые старые параметры не перечисляются в публичных заметках о пропусках.

Текущий сол в таблице не задан: используется сол 1. По уточнению прайма путешествие длится 11 солов; эта продолжительность устанавливается при импорте и по умолчанию для нового путешествия. Оба решения отдельно указаны в отчёте. Для нового альянса по механике задаются 200 заряда и 1 гравитон; импортированные фактические значения ими не заменяются.

В реальной выгрузке перенесено восемь альянсов, семь аванпостов без известных бонусов, восемь узлов и три поимённых шаттла. Текстовые бонусы у Гагарина сохранены заметками и не превращены в дополнительные владения.

## Высадки и совместимость аванпостов

Импорт и загрузка страницы не начинают высадку и не начисляют бонусы. `startCadiaLanding(state, allianceId)` явно открывает новую высадку на Кадию и задаёт 8 ОД, либо 10 ОД при установленном Десантном форсаже. Возвращается `{cycle, actionPoints}`; отдельные ОД райдеров не меняются.

`outpostBonusStatus(state, allianceId, recordId)` возвращает `{canClaim, label, reason}` без изменений данных. Закреплённый объект даёт бонус один раз на каждой следующей высадке; новый захват не даёт бонус в текущую высадку. `claimOutpostBonus` фиксирует `lastBonusCycle`. Неизвестный бонус нельзя начислить. Для старых копий без `bonusCycle` и `capturedCycle` действует прежняя проверка `claimed`; после явного старта новой высадки старый захват снова может дать бонус. `claimed` сохраняется для совместимости.

При новом захвате до первой отслеживаемой высадки записывается `capturedCycle=0`; бонус станет доступен только после явного старта высадки 1. Подробности источников без сценарных раскрытий: [genesis-sources.md](genesis-sources.md).
