# Орбита — космическая лагерная смена

HTML-сайт с общим прогрессом альянсов и единственным администратором. **Посетители только смотрят; организатор меняет данные после входа по паролю.** Права проверяются на сервере для каждого изменения. Пароль не включается в HTML или репозиторий.

Крышечки, опыт и уровни, пять подфункций, Кадия/Фенрис/Кронус, интерфейсы, 110 позиций каталога, покупки и крафт сохраняются в общей базе. Страница зрителя обновляется каждые 10 секунд. Пороги опыта, цены и рецепты редактирует организатор.

## Бесплатное размещение: Cloudflare Workers + D1

У Cloudflare Workers и D1 есть бесплатные тарифы. Для небольшой смены можно начать с них; точные ограничения доступны в [документации Workers](https://developers.cloudflare.com/workers/platform/pricing/) и [D1](https://developers.cloudflare.com/d1/platform/pricing/).

Сайт опубликован: **https://orbita-camp.emphaze-orbita.workers.dev**. Общая база подключена, пароль организатора настроен в Cloudflare. GitHub содержит исходники; GitHub Pages подходит только для HTML-копии просмотра, поскольку не выполняет серверную проверку прав.

Публикация новой независимой копии со своего компьютера (Node.js 24):

1. Скачайте этот репозиторий и выполните `npm ci`.
2. Выполните `npx wrangler login` и войдите в Cloudflare через браузер.
3. Создайте базу: `npx wrangler d1 create orbita-camp`.
4. В `wrangler.jsonc` замените `00000000-0000-0000-0000-000000000000` на выданный `database_id`. Этот ID не является паролем.
5. Выполните `npm run deploy`. Команда применит миграции базы и опубликует Worker вместе с HTML.
6. Выполните `npx wrangler secret put ADMIN_PASSWORD`. Введите свой уникальный пароль (12–256 символов) в защищённом запросе команды. Не записывайте его в HTML, GitHub или чат.
7. Откройте выданный адрес сайта. Для редактирования нажмите «Вход организатора». Остальным отправьте эту же ссылку — без пароля им доступен только просмотр.

Вместо интерактивного `wrangler login` для автоматического размещения можно использовать `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`. Токен должен иметь права Workers Scripts: Edit и D1: Edit для выбранного аккаунта. Вводите его только через защищённые настройки, не в исходники.

Начальные альянсы и участники вымышлены. После входа можно начать чистую смену или импортировать свою JSON-копию.

## Локальный сервер или VPS

Сервер использует Node.js 24 и встроенную SQLite; сторонние runtime-библиотеки не нужны.

```sh
# Скопируйте .env.example в .env и задайте свой ADMIN_PASSWORD.
node --env-file=.env server/local.js
```

По умолчанию сервер слушает порт 8081. Общая база находится в `data/orbita.sqlite`; каталог `data/` должен сохраняться между перезапусками. На публичном VPS используйте HTTPS-прокси и задайте `PUBLIC_ORIGIN` равным адресу сайта. При доступе по HTTPS сессионная cookie имеет флаг Secure. Локальные `.env` и `.dev.vars` исключены из Git.

Если пароль не задан, сервер запускается **только для просмотра**: он не предоставляет регистрацию и не разрешает редактирование никому.

## HTML-копия для просмотра

В `index.html` включены стили, JavaScript, шрифты и иллюстрации. Самостоятельное открытие файла или статический хостинг предоставляют только просмотр. Для защищённого редактирования и общего прогресса необходим сервер.

Организатор может скачать актуальную HTML-копию через настройки («HTML для зрителей»). В неё включаются текущие данные общей базы; при открытии файла без сервера редактирование недоступно. Такая копия является снимком и не обновляется автоматически.

Данные старой локальной версии не удаляются из браузера. Чтобы перенести их в общую базу, экспортируйте JSON из старой версии и импортируйте после входа организатора.

## Игровые правила

- Крышечки на балансе и заработанные за смену учитываются отдельно от опыта.
- Уровни зависят от настраиваемых порогов опыта. Найденные на карте уровни учитываются отдельно и сохраняются при начислении опыта. В данных «Генезиса» шаг составляет 100 опыта.
- Инженеры, астрофизики, астробиологи и архивариусы имеют репутацию. Райдеры — очки действий. ОД на Кадии учитываются отдельно.
- Результаты мероприятия начисляют фактические награды выбранным альянсам одной операцией.
- Бонус каждого аванпоста начисляется один раз для соответствующей записи.
- У интерфейса есть заряд, ёмкость, стойкость и гравитоны. Общая масса не ограничена десяткой; купить за смену можно до 10 гравитонов. Найденные или выданные вручную не расходуют этот лимит.
- В каталоге: 11 доступов, 27 улучшений, 42 предмета/способности и 30 инструментов. Числа инструментов — их уровни, а не цены.
- Известные цены сохранены. Неуказанные цены настраиваются организатором. Крафт расходует ингредиенты; дополнительное списание крышечек включается в правилах смены.
- Неоднозначные рецепты нужно подтвердить перед крафтом. «Форпост» в рецептах «Пионера» и «Магеллана» не заменён автоматически: организатор выбирает корректные ингредиенты.
- Покупка не применяет описанные способности автоматически. Игровые эффекты отмечает организатор через показатели.
- При смене сола активные доступы очищаются, история покупок сохраняется.

## Защита и сохранение

Перенос таблицы «Генезис», сохранение исходных заметок и обработка незаданных показателей описаны в [инструкции импорта](docs/genesis-import.md).

Сессии администратора хранятся в базе, cookie имеет HttpOnly и SameSite=Strict. Изменения требуют действующую сессию, CSRF-токен и совпадающий Origin. Неверные попытки входа ограничены. Выход немедленно отзывает сессию; смена пароля отзывает старые сессии. Пароли и сессионные токены не сохраняются в localStorage и не выдаются в HTML.

Сервер проверяет формат каждого сохранения. Версии данных защищают от перезаписи более свежих изменений из другой вкладки. Сбой сохранения не показывается как успех. Экспорт/импорт JSON доступен в настройках организатора; перед очисткой и импортом требуется подтверждение.

Исходники, база и конфигурация не раздаются HTTP-сервером. Для просмотра посетителям доступны только сайт и данные прогресса.

## Разработка и проверки

Используйте существующий checkout `/workspace/Emphaze`: задача уже изолирована, дополнительный Git worktree не нужен.

```sh
npm ci
npm test
python3 scripts/build_html.py  # после изменения src/
npm run build                 # подготовить public/index.html
```

Локальная проверка Cloudflare:

```sh
npm run db:local
# Для проверки входа создайте игнорируемый .dev.vars с собственным тестовым ADMIN_PASSWORD.
npm run worker:dev
```

`node --test tests/*.test.js` проверяет игровую модель, серверные права, CSRF, ограничения входа, отзыв сессий, версионность и SQLite. `python tests/browser_smoke.py` запускает свой изолированный сервер с временным тестовым паролем и проверяет весь интерфейс, зрителя и администратора. Для существующего тестового сервера задайте `SMENA_TEST_URL` и `SMENA_TEST_PASSWORD` через окружение. Не запускайте smoke-тест на реальной смене: он изменяет данные и проверяет очистку/восстановление.

`npx wrangler deploy --dry-run` проверяет сборку Worker без публикации. Настоящее размещение требует аккаунт Cloudflare, созданную D1 и пароль администратора.
